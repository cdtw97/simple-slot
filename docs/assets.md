# Asset credits

The cabinet face, eleven fruit illustrations, game mark and interface icons were drawn for Simple Slot. The symbol IDs in the SVG sprite match the server's fruit IDs. CSS supplies the cabinet trim, reel windows, lighting and palettes. Web Audio generates the spin, reel-stop, win, lamp and bonus cues at playback time.

DM Sans and Barlow Condensed are self-hosted with the game. Their SIL Open Font License notices are included alongside the fonts in `assets/fonts/`. Copyright belongs to the [DM Sans project authors](https://github.com/googlefonts/dm-fonts) and the [Barlow project authors](https://github.com/jpt/barlow).
